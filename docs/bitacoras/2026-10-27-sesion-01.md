## Problemas y aprendizajes

- **static-copy 4** copiaba el WASM con toda la ruta (`dist/mediapipe/wasm/node_modules/...`); se arregló con `rename: { stripBase: true }`.
- **Precache del WASM:** cada variante pesa unos 11 MB. Con `globPatterns: wasm`, como proponía §5.4, el build habría fallado; quedó en `globIgnores` con `CacheFirst` en tiempo de ejecución.
- **`erasableSyntaxOnly`** prohíbe las *parameter properties*, así que las clases declaran sus campos explícitamente.
- **Layout horizontal:** en la primera captura el soroban medía 225 px y las celdas, 16 px. Se rehízo con el soroban a altura completa y una columna lateral angosta; con 13 varillas en 844 px no hay otra forma de llegar a 44 px.
- **Encoding:** algunos scripts de Python escribieron en cp1252 y después Prettier convirtió los acentos de `vite.config.ts` en caracteres de reemplazo. Se corrigió, y de acá en más siempre `encoding='utf-8'`.
- **RTL sin `globals`:** React Testing Library no limpia el DOM entre tests; se agregó `cleanup` en `src/test/setup.ts`.
- **Commit con un test fallando:** `bb002f1` entró roto porque la cadena de comandos no cortaba con el error; lo arregló `12d204a`. Desde entonces, el commit depende del exit code de `npm run check`.
- **Herramienta de capturas:** para verlas se instaló `playwright-core` en el scratchpad (no en el proyecto) y se usó el Chromium del caché de Playwright, porque `chromium-cli` no está disponible.
