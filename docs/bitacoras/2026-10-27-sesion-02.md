## Problemas y aprendizajes

- **El `| tail` volvió a tapar el exit code:** el primer commit de la sesión entró con un error de Prettier. Se rehízo (todavía era local) y desde ahí el check se corre redirigido a un log, y el commit depende de `$?`.
- **Python en Windows escribe CRLF** si no se le pasa `newline='\n'`, y `.gitattributes` pide LF; Prettier lo marca. Usar siempre `encoding='utf-8', newline='\n'`.
- **Ramas muertas y cobertura del 100 %:** los `canApply` del motor nunca podían fallar, porque `dragMove` siempre produce movimientos válidos para el estado que recibe. Se sacaron en vez de inventar tests imposibles.
